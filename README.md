# Ultramarine Orb Elixir

[日本語](README.ja.md)

Ultramarine Orb Elixir (orb) is an unofficial tool that brings Legacy of Lunatic Kingdom's
Pointdevice mode to other Touhou games.

## Installing

Download `orb.exe` from the
[latest release](https://github.com/youxkei/ultramarine-orb-elixir/releases/latest), put it in the
folder the game's exe is in, and start the game with it instead.

The first launch asks how much of the screen the game gets and a few other things, and remembers
the answers.

## Which games

| | |
| --- | --- |
| The Embodiment of Scarlet Devil 1.02h | supported |
| Perfect Cherry Blossom | not supported |
